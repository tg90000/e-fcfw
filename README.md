# Analysis of the Behavior of the E-FCFW Algorithm

This repository contains a single notebook, `brief.ipynb`, in which I analyze the E-FCFW algorithm of
Pennington et al. (arXiv:2509.10657) and Liaqat et al. (arXiv:2610.10772), with the QAOA sampler replaced by
classical Goemans–Williamson sampling.

On request, I can provide the complete project: the implementation, all instances, the scripts and results, and a
full description of the experiments.
